# 🏆 Топляндия

Учебная платформа с рейтингом **топ-100 России** в реальном времени.
Решай задания, зарабатывай монеты 🪙 и алмазы 💎 и открывай разные топы.

## Возможности

- Регистрация с ником и регионом
- Задания, ответы на которые проверяет сервер (накрутка через запросы невозможна)
- Валюта: монеты за каждый верный ответ, алмаз за серию из 10 верных подряд
- Топы: день, неделя, месяц, год и олимпиадники
- Платный доступ к топам (открытый топ доступен 24 часа)
- Рейтинг обновляется у всех онлайн-игроков раз в секунду

## Цены топов

| Топ | Цена |
|---|---|
| День | бесплатно |
| Неделя | 50 🪙 |
| Месяц | 150 🪙 |
| Год | 400 🪙 |
| Олимпиадники | 5 💎 |

Цены и награды меняются в начале `server.js` (`PRICES`, `REWARD`).

## Запуск

Нужен Node.js 18 или новее. Зависимостей нет.

```bash
node server.js
```

Открой http://localhost:3000

Переменные окружения:

- `PORT` — порт (по умолчанию 3000)
- `DB_FILE` — путь к файлу данных (по умолчанию `data.json`)

## Размещение в интернете

1. Залей репозиторий на GitHub.
2. Подключи его к Render, Railway или Fly.io. Команда запуска: `node server.js`.
3. Подключи постоянный диск и задай `DB_FILE=/data/data.json`, иначе данные пропадут при перезапуске.

## API

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/register` | Регистрация, возвращает токен |
| GET | `/api/me` | Профиль и цены |
| GET | `/api/task?kind=easy\|olymp` | Новое задание |
| POST | `/api/answer` | Ответ на задание |
| POST | `/api/unlock` | Открыть топ за валюту |
| GET | `/api/top/:period` | Топ-100 (`day`, `week`, `month`, `year`, `olymp`) |
| GET | `/api/stream/:period` | Обновления топа в реальном времени (SSE) |

Токен передаётся в заголовке `x-token` или в параметре `?token=`.
